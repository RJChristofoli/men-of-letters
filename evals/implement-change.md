# implement-change

## Deve ativar

- "Implemente paginação neste endpoint e adicione os testes."
- "Refatore este serviço sem alterar o contrato público."
- "Corrija esta falha e valide o comportamento."

## Não deve ativar

- "Apenas encontre a causa deste erro."
- "Revise este pull request."
- "Compare duas alternativas antes de implementar."

## Sinais de qualidade

- Traduz o pedido em comportamento verificável.
- Preserva mudanças não relacionadas e contratos intencionais.
- Faz a menor alteração compatível.
- Relata validações executadas, falhas e verificações não realizadas.
